## Commitment 1: Primary Reviewer

### Role Definition
Conducts independent review of all 50 pilot units using the workbench. Records mapping decision, rationale, evidence references, and confidence for each unit.

### Responsibilities

| Responsibility | Detail |
|----------------|--------|
| **Review Scope** | All 50 pilot units (100% coverage) |
| **Decision Recording** | Mapping decision (ACCEPTED/REJECTED/AMBIGUOUS/UNMATCHED/NO_IFCT_EQUIVALENT/CONFLICT) |
| **Rationale** | Minimum 50 characters per decision; cite specific evidence fields |
| **Evidence References** | 15 mandatory fields for ACCEPTED; ≥3 for other decisions |
| **Confidence** | 1-5 scale per decision |
| **Auto-Accept Verification** | Manually verify all 5 criteria for the 3 auto-accepted units |
| **Timeline** | Complete 50 units within 1-2 weeks of pilot start |
| **Calibration** | Complete 5-unit calibration set independently; achieve consensus with auditor |
| **Blind Protocol** | Do not discuss decisions with auditor until after adjudication |
| **Data Integrity** | Do not modify frozen candidate data; record decisions only |

### Expected Workload

| Activity | Estimated Time |
|----------|----------------|
| Calibration | 1-2 hours |
| Primary Review (50 units) | 10-15 hours |
| Total | 11-17 hours over 1-2 weeks |

### Independence Requirements

- No prior involvement in candidate generation for pilot units
- No communication with auditor about specific unit decisions during review
- No access to auditor's workspace or decisions
- Separate physical machine or isolated browser session

## Commitment 3: Domain Expert 1 (Adjudication Panel Chair)

### Role Definition
Serves as chair of the adjudication panel. Provides binding resolution of disagreements between primary reviewer and quality auditor. Defines 48-hour SLA for resolution.

### Responsibilities

| Responsibility | Detail |
|----------------|--------|
| **Adjudication Scope** | All disagreements between primary and auditor on 10-unit audit sample |
| **Panel Role** | Chair; binding resolution authority |
| **SLA** | 48 hours from notification to written resolution |
| **Review Process** | Independently reviews primary + auditor decisions, rationales, evidence, IFCT data |
| **Deliberation** | Confers with Domain Expert 2; reaches binding consensus |
| **Documentation** | Written rationale per case citing specific evidence; signed by both experts |
| **Authority** | Binding resolution; final mapping decision for adjudicated units |
| **Availability** | On-call for 48h SLA during adjudication period (estimated 1-2 days) |
| **Calibration** | Review calibration set and consensus record to understand decision framework |
