# Stage 3.4: User Guide - Ingredient Review Workbench

**Date:** 2026-11-18  
**Version:** 1.0  
**Application Version:** 1.0.0

## Overview

The Ingredient Review Workbench is a Streamlit-based web application for reviewing and approving ingredient-to-IFCT (Indian Food Composition Tables 2017) mappings. It provides an interactive interface for reviewers to evaluate, accept, reject, or escalate ingredient-to-IFCT mappings generated by the Stage 2.3 candidate generation pipeline.

## 2. Review Interface

### Main Panel (Left)

#### Candidate Comparison Panel
Displays side-by-side comparison:
- **Source Ingredient**: Original, normalized, primary ingredient, preparation state, quantity/unit
- **IFCT Candidate**: Food code, name, group, full nutrient profile (per 100g)
- **Match Info**: Match method, similarity score, confidence level

#### Review Decision Form

| Field | Description |
|-------|-------------|
| **Mapping Decision** | ACCEPTED / REJECTED / AMBIGUOUS / UNMATCHED / NO_IFCT_EQUIVALENT |
| **Confidence (1-5)** | Your confidence in this decision |
| **Alternative IFCT Code** | Optional alternative IFCT code if rejecting |
| **Rationale** (min 50 chars) | Required explanation citing specific evidence |
| **Evidence References** | Comma-separated list of evidence fields used |
| **Uncertainty Notes** | Optional caveats or limitations |

### Decision Types

| Decision | When to Use |
|----------|-------------|
| **ACCEPTED** | Identity + prep + species all confirmed; evidence score ≥4 |
| **REJECTED** | Core identity mismatch OR prep incompatible without evidence |
| **AMBIGUOUS** | >1 IFCT code equally plausible after full review |
| **UNMATCHED** | No candidate survives scrutiny |
| **NO_IFCT_EQUIVALENT** | Ingredient genuinely absent from IFCT 2017 |

### 1.4 Evidence References (Mandatory for ACCEPTED)

When marking **ACCEPTED**, you must provide comma-separated evidence references from this list:

| Field | Description |
|-------|-------------|
| `ifct_food_code` | IFCT food code |
| `ifct_food_name` | Official IFCT food name |
| `ifct_food_group` | IFCT food group |
| `ifct_source_page` | IFCT 2017 page number |
| `ifct_table_number` | IFCT table number |
| `match_method` | EXACT/SYNONYM/etc. |
| `similarity_score` | 0.0–1.0 |
| `preparation_state` | RAW/FRESH/DRIED/etc. |
| `preparation_confidence` | 0.0–1.0 |
| `prep_state_compat` | 0.0–1.0 |
| `extracted_aliases` | JSON array |
| `ambiguity_flags` | JSON array |
| `ifct_source_page` | IFCT 2017 page number |
| `ifct_table_number` | IFCT table number |
| `species_verification` | Scientific name match |
| `edible_part_verification` | Edible part match |
| `prep_compatibility_evidence` | How prep state matches IFCT basis |

**All 15 fields mandatory for ACCEPTED decisions.**

## 4. Reviewer Workflow

### 1. Login
Enter your **Reviewer ID** in the sidebar. This ID is attached to all your decisions.

### 2. Calibration
Before starting, complete the **5-unit calibration set** (see `reports/phase3/stage3_4_calibration_set.md`). Compare your decisions with the expected answers.

### 3. Review Loop
1. **Review evidence panel** (left): source ingredient, IFCT candidate, nutrient profile
2. **Evaluate** using the decision matrix
3. **Record decision** with rationale (≥50 chars) and evidence refs
4. **Save** → auto-advances to next unit

### Decision Matrix

| If... | Then... |
|-------|---------|
| Identity + prep + species confirmed; evidence score ≥4 | → **ACCEPTED** |
| Core identity mismatch OR prep incompatible (no evidence) | → **REJECTED** |
| >1 IFCT code equally plausible | → **AMBIGUOUS** |
| No candidate survives scrutiny | → **UNMATCHED** |
| Ingredient genuinely absent from IFCT 2017 | → **NO_IFCT_EQUIVALENT** |

### 3. Evidence Requirements for ACCEPTED

**All 15 fields mandatory:**
```
ifct_food_code, ifct_food_name, ifct_food_group,
ifct_source_page, ifct_table_number,
match_method, similarity_score,
preparation_state, preparation_confidence,
prep_state_compat, extracted_aliases,
ambiguity_flags, ifct_source_page,
ifct_table_number, species_verification,
edible_part_verification, prep_compatibility_evidence
```

### 4. Rationale Requirements
- Minimum 50 characters
- Must cite specific evidence fields
- No vague statements ("looks good", "seems right")

---

## 3. Special Cases

### Multi-Code Ambiguity
If >1 IFCT code equally plausible after full evaluation → **AMBIGUOUS**. Do not pick one.

### NOT_SPECIFIED Preparation
- **Never auto-accepted**
- Requires explicit reviewer evidence: "recipe_context_implies_raw"
- Update preparation_state to FRESH/RAW after confirmation

### Composite Ingredients
Ingredients like "ginger garlic paste" → mark AMBIGUOUS or decompose

### Unmatched Ingredients
If no candidate survives scrutiny → **UNMATCHED** or **NO_IFCT_EQUIVALENT**

## 5. Exporting Decisions

### Export Options
- **Reviewed Mappings** (ACCEPTED)
- **Pending Mappings** (REVIEW_REQUIRED)
- **Rejected Mappings** (REJECTED)
- **Ambiguous Mappings** (AMBIGUOUS)
- **Escalated Mappings** (ESCALATED)
- **Review History** (full audit trail)

### Export Formats
- **Parquet** (primary, preserves types)
- **CSV** (human-readable)

### Export Contents
Each export includes:
- All decision fields
- Full provenance (recipe_id, original text, timestamps)
- Evidence references
- Reviewer ID and timestamps

## 5. Calibration

Before starting production review, complete the **5-unit calibration set** (`reports/phase3/stage3_4_calibration_set.md`):

1. Review all 5 calibration units independently
2. Compare your decisions with expected answers
3. Discuss discrepancies with calibration coordinator
4. Only proceed to production after calibration consensus

## 6. Troubleshooting

| Issue | Solution |
|-------|----------|
| App won't start | Check `streamlit --version` ≥ 1.67; verify all packages installed |
| Data not loading | Verify SHA-256 hashes of frozen inputs match Appendix |
| Decisions not saving | Check `data/interim/phase3/decisions/` write permissions |
| IFCT data not loading | Verify `data/interim/ifct_final_candidate/ifct_table1_candidate.parquet` exists |
| Slow performance | Reduce filtered dataset size; use filters |
