## 8. Scientific integrity notes

- The paper states that **no validated recipe-level nutrition is available**: zero
  approved IFCT mappings, 1.43 % gram-weight coverage, 34.1 % edible-portion
  coverage, 42 % missing fibre/carbohydrate, 88.6 % unspecified preparation state.
- Proxy relevance is explicitly identified as circular (it reuses the rankers'
  features) and is never described as user satisfaction or dietary usefulness.
- The abstract and conclusion do **not** claim that TF-IDF is superior in general —
  only that it has the highest composite score among four methods, while failing two
  of the project's four operational requirements.
- The four-identical-configurations defect is disclosed as a defect.
- No synthetic test result is presented as a real-world experimental result; the 42
  nutrition-engine unit tests are described as tests, not as validation on data.
- No medical or clinical claim is made about the target calculations.

## 9. Known limitations of this deliverable

1. **Author block is a placeholder** (`Author Name`, `Department, Institution`,
   `author@example.org`). The project contains no verified author names,
   affiliations or addresses, so none were invented. This must be filled in before
   submission.
2. **Fonts:** the PDF uses TeX Gyre Termes, the standard free Times clone, because
   Times New Roman is not available to this TeX installation. IEEE accepts Times or
   a Times-compatible face; substituting the official class on a machine with the
   Microsoft core fonts will produce byte-different but visually equivalent output.
3. **Evaluation scope:** 50 queries, one corpus, one proxy. The paper says so; the
   numbers should not be compared with published benchmarks collected under
   different protocols.
4. **Page count is exactly 6** with the current text. Any added paragraph will push
   to 7 pages; trim an equivalent amount if content is added.
5. During authoring, `IEEE_Research_Paper.tex` was briefly locked by a running Word
   process (a `~$EE_Research_Paper.tex` lock file was present), so the paper was built
   from a temporary copy. The lock has since been released, the corrected source was
   written to `IEEE_Research_Paper.tex`, and the PDF in this folder was recompiled from
   that canonical file (6 pages, 15 references). The temporary copy has been deleted.
